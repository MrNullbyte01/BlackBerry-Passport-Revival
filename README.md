# BlackBerry Passport Revival

A personal BlackBerry Passport revival project focused on restoring and extending the device's practical use through software setup, emulation, remote access, and terminal workflows.

> **Status:** The device has been brought back into use. This repository is being expanded into a reproducible technical case study; exact OS version, application versions, and test evidence still need to be recorded.

## Work completed

The project notes currently record these hands-on results:

- Set up an AI-related workflow on the device. The exact application, model/service, and runtime details still need to be added.
- Launched a Windows 98 emulation environment.
- Configured SSH for remote access.
- Used a terminal workflow with direct access to the device's filesystem.
- Customised the device's software environment as part of the revival process.

These are personal project activities, not claims of original software development. Third-party applications and tools should be credited where applicable.

## What this project demonstrates

- Reviving and configuring older mobile hardware.
- Working with legacy mobile software and application compatibility.
- Using terminal-based workflows and filesystem navigation.
- Configuring remote access with SSH.
- Exploring emulation and lightweight AI-related workflows on constrained hardware.
