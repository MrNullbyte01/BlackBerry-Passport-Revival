## File handling note

The packages above are not copied into this repository at this stage because they appear to include third-party application binaries and their redistribution licences or permissions have not been verified. The original archive remains in the portfolio repository under `projects/blackberry-passport/APK/` and `projects/blackberry-passport/BAR/`.

Before mirroring any package here, verify its source, licence, and permission to redistribute it. Do not upload modified or repackaged application binaries without the relevant rights.
